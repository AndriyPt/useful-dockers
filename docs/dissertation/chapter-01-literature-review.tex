\section{Аналіз дослідження}

Нормативи оформлення:

1) Кожен абзац літературного огляду подається у формі порівняльного аналізу або резюме того, чи іншого висновку із
першоджерела з припущеннями чи висновками інших авторів (особливо важливо виявити протиріччя у висновках різних авторів
на вирішення однієї і тієї ж проблеми; "посваривши" таким чином двох чи більше авторів і, на цій підставі, зробити свій
висновок; доцільно підтвердити існування невирішеної проблеми та актуальність її вирішення).

2)Кожен абзац літературного огляду, якщо він не відображає власну думку, а надає інформацію з інших першоджерел, повинен
завершуватися посиланням на конкретне першоджерело, яке повинно бути у розділі «Список використаних джерел»

Повнота цієї частини дослідження досягається шляхом пошуку і завантаження тематичного матеріалу, який у свою чергу вже
має власний список літератури та огляд. Кожна позиція повинна бути вивчена і проаналізована.

Пошук нових джерел припиняється, якщо після опрацювання та аналізу безлічі статей в наступних матеріалах не
зустрічаються нові публікації та прізвища. Наступним етапом стає побудова змістовної частини, розподіл за авторськими
концепціями та школами.

Статті, де розглядаються неоднорідні задачі, розв'язані методом граничних елементів:

\begin{itemize}

\item "Метод граничних елементів в задачах з нестійкими розв'язками": Автори В.Ф. Оробей, А.Ф. Дащенко та А.М. Лимаренко
з Одеського національного політехнічного університету показують застосування алгоритму чисельно-аналітичного варіанта
методу граничних елементів для збільшення стійкості розв'язання задач з великими коефіцієнтами фундаментальних функцій.

\item "Метод граничних елементів в задачах стійкості плоскої форми вигину балок прямокутного перерізу": У цій статті
В.Ф. Оробей, А.Ф. Дащенко та Л.В. Коломієць розглядають алгоритм розв'язання задач стійкості плоскої форми вигину балок
прямокутного перерізу за допомогою чисельно-аналітичного варіанта методу граничних елементів.

\item "Метод граничних елементів в задачах визначення напружено-деформованого стану в неоднорідному масиві": У цій
статті розроблено чисельний алгоритм визначення напружено-деформованого стану в неоднорідному масиві, що складається з
двох лінійно-пружних підобластей.

\item "Boundary Element Methods for Engineers and Scientists": Ця стаття розглядає основні принципи та застосування МГЕ
в інженерії та науці, включаючи задачі для неоднорідних тіл.

\item "The Boundary Element Method in Acoustics": У цій статті розглядається застосування МГЕ для вирішення задач
акустики, зокрема для неоднорідних середовищ.

\item "Boundary Element Analysis of Plates and Shells": Ця стаття присвячена застосуванню МГЕ для аналізу пластин та
оболонок, включаючи неоднорідні матеріали.

\item "Numerical analysis of stress distribution in back-filled stopes considering interfaces between the backfill and
rock walls": У цій статті розглядається чисельний аналіз розподілу напружень у заповнених виробках з урахуванням
інтерфейсів між заповнювачем та стінками породи.

\end{itemize}


\section{Ситуація з науковими школами}

Наукові школи, які активно використовують метод граничних елементів (МГЕ):

\begin{itemize}

\item Національний технічний університет "Дніпровська політехніка": Вчені цього університету використовують МГЕ для
моделювання напружено-деформованого стану в неоднорідних масивах.

\item Вінницький національний технічний університет: Дослідники застосовують МГЕ для розрахунків кільцевих фундаментів.

\item Одеський національний політехнічний університет: Вчені цього університету, зокрема В.Ф. Оробей, А.Ф. Дащенко та
А.М. Лимаренко, застосовують МГЕ для вирішення задач з нестійкими розв'язками.

\item Тернопільський національний технічний університет імені Івана Пулюя: Дослідники, такі як Д. Биків під керівництвом
С.І. Федака, використовують МГЕ для визначення частот та форм власних коливань стержневих систем.

\item Національна академія наук України: Вчені цієї установи також працюють над застосуванням МГЕ до різних задач теорії
пружності та згину платівок.
\end{itemize}

Ці приклади демонструють широке застосування методу граничних елементів у різних наукових установах України.
